Restaurant Sales Analytics

Project Overview

An end-to-end restaurant sales analysis project using Python, Pandas, SQL, and Excel.

Tools Used

- Python
- Pandas
- SQLite
- SQL
- Excel

Project Objectives

- Clean and validate restaurant sales data.
- Identify top-performing branches and products.
- Analyze monthly revenue trends.
- Compare payment methods.
- Generate an Excel management report.

Key Findings

- Total net sales: ₹61,601
- Best-performing branch: Dankuni
- Top revenue-generating product: Pizza

Project Files

- "restaurant_sales_project.py" — Python project script
- "restaurant_sales_raw.csv" — Original dataset
- "restaurant_sales_clean.csv" — Cleaned dataset
- "restaurant_analytics.db" — SQLite database
- "Restaurant_Management_Report.xlsx" — Excel report
